18 Revit tools across six focused panels

Every command is built around a repeatable structural production task—from sheet setup and schedule exchange to pile spacing checks.

Annotations & Sheets6 tools

01

Create Sheets

Create sheets from an Excel register, including title block, drawing category and series parameters.

02

Assign Views on Sheets

Place views on selected sheets with typed offsets or picked calibration points.

03

Export Drawings

Export sheets, print sets or revisions to PDF, DWG or DWF with custom file naming.

04

Export & Import Schedules

Round-trip schedule data through Excel, matching rows by element GUID.

05

Annotation Fixer

Check selected sheets for annotations outside the title block and align issues to a reference.

06

Element History

Log added and modified elements, or inspect the recorded history of selected elements.

Model Modification2 tools

07

Apply Coping

Find intersecting bracing members and apply coping, with optional columns as cutting members.

08

Join Geometry

Join elements between two chosen categories in the active view, with optional cut priority.

Beam Tools3 tools

09

Concrete Beam Number

Number in-situ concrete beams in plan order—horizontal first, then vertical—and write to Mark.

10

Steel Beam Number

Number hot-rolled steel beams in the same plan order and add an SB prefix to Mark.

11

Beam Coordinates

Write beam start, end and centre X/Y values in survey-point coordinates.

Column Tools2 tools

12

Column Number

Group columns into vertical runs and assign one mark per run, with C, TC or FC prefixes.

13

Column Split

Split columns at chosen levels while keeping the original mark and zero base/top offsets.

Pile Tools3 tools

14

Pile Coordinates

Write pile coordinates transformed from Revit internal coordinates to survey-point coordinates.

15

Pile Number

Number piles by prefix, start number, family filter and chosen numbering direction.

16

Pile Spacing

Check round-pipe piles against a minimum centre spacing based on a factor of pile diameter.

Wall Tools2 tools

17

Wall Number

Number selected walls by plan position and write the result to Mark, with W, TW, RW or WT prefixes.

18

Wall Split

Split walls at chosen levels while keeping the original mark and zero base/top offsets.

System Requirements

  • Autodesk Revit 2025 and above
  • Operating system Windows 10/11, 64-bit
  • Platform pyRevit with the IronPython 2.7 engine
  • Workflow pyRevit extension

Installation

  1. Install pyRevit for your Revit version.
  2. Download the Sukhvir BIM Suite extension package.
  3. Add the extension folder in pyRevit settings.
  4. Reload pyRevit or restart Revit.
  5. Open the Sukhvir BIM Suite ribbon tab.
Built on pyRevitRuns inside Revit with no Dynamo graphs or separate desktop app. Review results before issuing models and drawings.
