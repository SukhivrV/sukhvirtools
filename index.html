Structural automation, without the repetitive work.

StructiFlow brings the everyday structural BIM tasks you repeat most into one simple workflow inside Revit.

Automated Numbering

Number piles, columns, concrete beams, steel beams and walls using intelligent spatial ordering.

Element Splitting

Split columns and walls at intermediate levels without repeating the same manual modelling steps.

Documentation

Create sheets from Excel, assign views and make repetitive documentation tasks faster.

Annotation Fixing

Identify annotation clashes and help move tags away from overlapping elements for cleaner drawings.

Coordination

Join geometry and apply structural coordination operations directly from the Revit workflow.

Pile Coordinates

Extract pile survey coordinates and key pile information for structural documentation workflows.

System Requirements

  • Autodesk Revit 2025 and above
  • Operating system Windows 10/11, 64-bit
  • Runtime .NET 8.0
  • Workflow Standalone Revit add-in

Installation

  1. Download the installer when the release is available.
  2. Run the installer and follow the prompts.
  3. Restart Revit after installation.
  4. Open the Sukhvir Automation ribbon tab.
  5. Start using the tools in your production model.
Designed for a simple workflowNo Dynamo graph or pyRevit installation is intended to be required for the standalone release.
