StructiFlow by Sukhvir

Version 1.0 · Revit 2025 and above

A structural automation suite for Autodesk Revit. Includes 13 tools for numbering, splitting, coordination, and documentation workflows.

Download Installer

Run the installer and restart Revit. The tools will appear under the Sukhvir Automation tab.

System Requirements

  • Autodesk Revit 2025 and above
  • Windows 10/11 (64-bit)
  • .NET 8.0 Runtime

Installation

  1. Download the installer above.
  2. Run StructiFlow by Sukhvir.exe.
  3. Follow the on-screen prompts.
  4. Restart Revit.
  5. Find Sukhvir Automation on the ribbon.
